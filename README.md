# BEYOND DIFF. LAB

**Small rules. Big surprises.**

直感的な操作と数学的な発見を研究する4作品入りのブラウザゲームラボです。外部ライブラリ不要の単一 `index.html` で動作します。iPhone縦画面に最適化しています。

## FLOW SPLITTER v2のルール

1. 上に並んだ色玉が **左から1球ずつ** 流れます。
2. 分岐の矢印は、玉を流す最初の方向を示します。
3. **玉が通るたび、矢印は反対向きに切り替わります。**
4. すべての玉が進んだ後、各出口の色玉の **種類と個数** を目標と一致させればクリアです。出口内の並び順は問いません。

旧版の「交差・合流したときの優先順位」という見えない追加規則は廃止しました。玉は各分岐で左右に振り分けられ、合流することはありません。

序盤は分岐1個、中盤は3個、後半は5個。短い導入から複数経路の推理に進みます。

### 操作

- 白い丸い矢印をタップ：その分岐の最初の向きを変更
- **1球ずつ**：1球の動きと、通過した分岐の反転を確認
- **まとめて流す**：すべての玉を順に流す
- **結果を見る**：アニメーションを省略して、最終結果をすぐ確認
- 不正解の場合は矢印を変更して再挑戦

タッチ操作、音のON/OFF、成功演出、進捗・プレイ評価の保存に対応しています。
